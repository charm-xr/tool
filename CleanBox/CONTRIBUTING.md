# 参与开发

欢迎提交问题和改进。请先阅读 README 中的功能边界。

## 开发流程

1. 在 Windows 10/11 x64 克隆仓库。
2. 执行 `./build.ps1`。
3. 修改相关代码后运行 `CleanBox.exe --self-test`，等待退出并检查 `data/test-results.txt`。
4. 界面改动可使用 `--ui-check` 生成预览；预览包含本机软件信息，不要直接提交。
5. 通过 Pull Request 说明用户可观察到的行为、验证方式以及尚未验证的情况。

## 文件处理原则

- 删除前显示准确路径，保留永久删除确认和目录边界保护。
- 不跟随目录联接，不把模糊名称匹配结果直接批量删除。
- 结束进程前核对路径和启动时间，保留系统与关键进程保护。
- 将部分成功和部分失败分别报告，不把请求已登记等同于删除已完成。
- 破坏性测试只能使用新建的专用样例，不卸载开发者现有软件。

## 公开内容

根目录使用 `.gitignore` 白名单。需要加入新的公开文件时，请同时更新白名单。

不要提交真实软件清单、操作日志、注册表导出、截图中的个人路径、账号或凭据。问题报告中同样应移除这些信息。
